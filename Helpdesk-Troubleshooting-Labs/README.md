# Helpdesk & Troubleshooting Labs

Simulated IT support scenarios covering the full ticket lifecycle — triage, root cause analysis, resolution, and documentation. All labs use Jira Service Management and follow industry-standard troubleshooting methodologies.

**Environment:** Windows Server 2022 (labs.local) · Windows 11 Enterprise · Windows 10 VM  
**Tools:** Jira Service Management, Active Directory, Event Viewer, Resource Monitor, Task Manager

| # | Activity | Focus |
