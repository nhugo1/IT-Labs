# Ticketing & Troubleshooting Lab Series

This section of my portfolio documents a series of real-world IT support scenarios. Each activity focuses on the intersection of **ITSM Workflow (Jira)** and **Technical Remediation (Active Directory/Systems Administration)**.

The goal of this series is to demonstrate competency in handling common enterprise tickets while maintaining high security standards and thorough documentation.

## ⚙️ Lab Environment Architecture

To ensure these simulations are accurate to an enterprise environment, the following infrastructure is utilized:

* **Client Endpoint:** Windows 11 Enterprise (Joined to `Labs.local` domain)
* **Virtualization:** Oracle VirtualBox
